# 模型视界LQZ browser CAD assets

This public repository contains a browser-side X_T parsing component for the model viewer. User model files are not stored here.

The parser and tessellator are built from [CadConvert](https://github.com/omerbasavul/cadconvert), revision 6046d1369949a09fa236f6bcf5f804eedb328685. See its MIT license and the Apache-2.0 license declarations in its Rust workspace. The workflow uses a sequential browser build and verifies it against its public sample before publishing.
